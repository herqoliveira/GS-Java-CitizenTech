# Architect Drone

## Ficha da CitizenTech

**Nome da CitizenTech:** Architect Drone.

**Cidade e bairro:** Cidades e bairros que necessitam de inovação, abrangendo áreas urbanas e rurais.

**Cidadão beneficiado:** Arquitetos, urbanistas e profissionais de áreas relacionadas.

**Problema, em uma frase:** Falta de dados estruturados ao planejar uma inovação na cidade ou no campo.

**Como funciona:** A proposta utiliza um drone equipado com tecnologia LiDAR para realizar levantamentos de um local. Os dados coletados, processados com o auxílio de inteligência artificial, servirão de base para mapas, plantas e modelos 3D que apoiem o trabalho dos profissionais.

**O que cada parte faz:**

- **Drone com LiDAR:** realiza a coleta de dados topográficos do local.
- **Agente de IA:** auxilia no processamento e na organização dos dados para gerar materiais de apoio aos arquitetos, sujeitos à revisão profissional.

**Indicador de impacto:** Redução do tempo necessário para coletar e organizar informações de uma região, comparando levantamentos de escopo equivalente realizados pelo processo habitual e com o Architect Drone.
